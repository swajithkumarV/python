# Zomato Food Prediction

## Overview
This project analyzes Zomato restaurant data using Python and data visualization techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files
- app.py : Main Python script
- Zomato-data-.csv : Dataset

## Features
- Data Cleaning
- Data Analysis
- Correlation Heatmap
- Visualization using Matplotlib and Seaborn

## How to Run

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
python app.py
```
